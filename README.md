# 邮件助手（Windows 桌面版）

一个在 Windows 桌面上运行的邮件整理小工具：连接 Gmail、QQ 邮箱和清华大学邮箱，每天定时检查新邮件，按主题自动分类，并通过可展开的桌面悬浮卡片查看晨报。

> **适合谁使用？** 希望把多个邮箱的未读/新到邮件汇总到一个轻量桌面窗口，并在每天早上快速了解重点邮件的 Windows 用户。
>
> **隐私原则：** 邮件在本机读取和分类，不会把邮件正文、附件或邮箱密码上传到本仓库或云端 AI 服务。

## 功能一览

- 支持 Gmail、QQ 邮箱、清华大学学生邮箱；可以只接入一个，也可以同时接入多个。
- 桌面右下角显示简洁的浅色置顶卡片，可拖动位置、展开/收起详情。
- 展开后按邮件卡片展示邮箱来源、发件人、主题、分类、时间和最多 220 字的正文摘要；点击卡片可打开对应邮箱网站。
- 每日定时检查，默认 **08:00**；可在设置窗口修改。
- 新邮件分为六类：紧急/待处理、课程与学术、求职与实习、账单与账户、订阅与通知、个人与其他。
- 发现新晨报时自动展开，约 25 秒后收起；也可手动展开查看。
- 使用 IMAP SSL 连接收件箱，并以只读方式读取邮件，不主动发送、删除、移动邮件或标记已读。
- 首次运行最多检查最近 100 封邮件中的近 24 小时邮件；后续按邮件 UID 跟踪新增邮件。
- 邮箱凭据通过本机系统凭据库保存；配置、同步状态、晨报元数据与每封邮件最多 220 字的正文摘要保存在本地用户目录。

## 一、下载与安装

### 系统要求

- Windows 10 或 Windows 11。
- Python 3.11 或更新版本。安装 Python 时建议勾选 **Add Python to PATH**。
- 安装时需要网络连接，以下载 Python 依赖。

### 第 1 步：下载项目

1. 打开本项目 GitHub 页面：<https://github.com/zishengliu/mail-briefing-assistant>。
2. 点击绿色 **Code** 按钮，再选择 **Download ZIP**。
3. 下载完成后，右键 ZIP 文件，选择“全部解压”。
4. 打开解压后的文件夹，确认其中能看到 `install_windows.ps1`、`mail_briefing.py`、`launch.bat` 和 `requirements.txt`。

不要在 ZIP 压缩包内部直接运行脚本。

### 第 2 步：在项目文件夹中打开 PowerShell

推荐用以下方法，确保命令在正确目录执行：

1. 在文件资源管理器里打开刚才解压的项目文件夹。
2. 点击窗口顶部的地址栏。
3. 输入 `powershell`，然后按 Enter。
4. 在 PowerShell 中输入 `dir` 并按 Enter，检查列表里是否能看到 `install_windows.ps1`。

如果看不到这个文件，请先进入正确的解压目录。也可以在文件夹空白处按住 Shift 后点击右键，选择“在终端中打开”（不同 Windows 版本的文字可能略有不同）。

### 第 3 步：执行安装脚本

在 PowerShell 中逐条执行以下命令，每条执行完成后再输入下一条：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

如果系统询问是否更改执行策略，输入 `Y` 并按 Enter。这个选项只作用于当前 PowerShell 进程。

然后执行：

```powershell
.\install_windows.ps1
```

安装脚本会执行以下操作：

1. 将程序文件复制到本机 `%LOCALAPPDATA%\MailBriefingAssistant`。
2. 创建独立 Python 虚拟环境并安装依赖。
3. 注册 Windows 登录启动任务。
4. 在开始菜单创建两个快捷方式：**邮件助手**（打开悬浮小插件）和 **邮件助手 - 设置**（配置邮箱与定时选项）。
5. 安装完成后尝试启动桌面悬浮小插件。

如果 PowerShell 报错，先保留完整报错内容，不需要立即重复安装；请参照本文“常见问题”部分排查。

## 二、配置邮箱

首次使用时，打开开始菜单中的 **邮件助手 - 设置**。在“邮箱与定时设置”页中，为需要连接的邮箱勾选“启用”，填写完整邮箱地址与对应的**客户端密码或授权码**，然后点击“保存设置”。

> 请勿把邮箱网页登录密码、授权码或任何真实凭据提交到 GitHub、截图或公共问题中。密码输入框会隐藏输入内容。

### 1. Gmail

- 邮箱地址：完整 Gmail 地址，例如 `name@gmail.com`。
- 客户端凭据：按照你的 Google 账号实际支持的方式配置。当前版本的轻量接入方式使用 Gmail IMAP 与应用专用密码；这不是 Google 网页登录密码。
- 应用专用密码通常要求开启两步验证，部分学校/公司管理账号或受高级保护计划约束的账号可能不支持。
- 如果 Google 不提供应用专用密码，请先检查账号安全政策。当前版本尚未实现 Gmail OAuth 授权，不要反复输入普通登录密码。

官方入口：[Google 账号安全设置](https://myaccount.google.com/security) · [应用专用密码](https://myaccount.google.com/apppasswords)

### 2. QQ 邮箱

- 邮箱地址：完整的 QQ 邮箱地址，例如 `123456@qq.com`。
- 登录 [QQ 邮箱网页版](https://mail.qq.com/)。
- 打开“设置 → 账户”，找到 IMAP/SMTP 服务，按页面提示启用服务并生成授权码。
- 在邮件助手中输入授权码，而不是 QQ 登录密码。

### 3. 清华大学学生邮箱

- 邮箱地址：填写清华邮箱网页端显示的完整地址。
- IMAP 服务器：`mails.tsinghua.edu.cn`。
- SSL 端口：`993`。
- 密码：按学校邮箱的客户端设置/安全设置生成或配置客户端专用密码。实际可用方式以学校账号政策为准。

参考：[清华大学邮箱官方客户端设置说明](https://mail.tsinghua.edu.cn/coremail/help/clientoption.jsp?locale=zh_CN)。

### 保存并测试连接

1. 在相应邮箱行勾选“启用”。
2. 填写完整邮箱地址与客户端密码/授权码。
3. 点击“保存设置”。
4. 点击“测试已启用邮箱”。每个邮箱都会单独显示连接成功或失败原因。
5. 如果某个邮箱失败，先核对邮箱地址、客户端密码/授权码、IMAP 服务是否启用，再检查学校或组织是否限制第三方客户端访问。

可以先只启用一个邮箱进行测试；确认成功后，再依次添加其他邮箱。未填写地址的邮箱会自动跳过。

## 三、日常使用

### 打开桌面悬浮小插件

- 从 Windows 开始菜单搜索并点击 **邮件助手**。
- 小插件默认以紧凑卡片形式显示在桌面右下角并保持置顶。
- 可以拖动标题区域调整位置。
- 点击“详情”展开邮件列表；每张卡片以邮箱来源标签、分类、时间、发件人、主题和简短正文摘要排列，点击“收起”折叠，邮件较多时可用鼠标滚轮浏览。
- 点击列表中的邮件，会打开它所属的邮箱网站。
- 点击“设置”可打开邮箱与每日检查时间设置。
- 点击右上角的 `×` 会退出小插件，不只是隐藏窗口。需要重新打开时，再从开始菜单启动“邮件助手”。

### 手动检查新邮件

1. 从开始菜单打开 **邮件助手 - 设置**。
2. 点击“立即检查新邮件”。
3. 助手会连接已启用且已填写地址的邮箱，并在列表中展示新发现的邮件分类。
4. 手动检查发现的邮件会暂存为待晨报项目，下一次定时晨报仍可汇总这些邮件。

### 修改每日提醒时间

1. 打开 **邮件助手 - 设置**。
2. 在“每日晨报”栏中填写 24 小时制时间，例如 `08:00` 或 `07:30`。
3. 点击“保存设置”。
4. 保持电脑开机、用户已登录，并让悬浮小插件运行。到设定时间后程序会自动检查邮件并展开晨报。

**电脑关机或用户未登录期间，程序无法联网检查。** 如果错过当天的定时检查，登录后启动小插件时，会在当天晨报尚未生成的情况下补跑。

### 退出后重新打开

如果不小心关闭了悬浮小插件：

- 最简单的方式：从开始菜单再次打开 **邮件助手**。
- 也可以在项目解压目录运行 `launch_widget.bat`。
- 如果只想修改邮箱信息，打开 **邮件助手 - 设置** 或运行 `launch.bat`。

如原版本没有“邮件助手”快捷方式，请按“更新已安装的版本”重新运行安装脚本，以创建新的快捷方式。

## 四、更新项目

当 GitHub 仓库发布更新后：

1. 从仓库下载最新 ZIP 并解压到一个新文件夹。
2. 在新文件夹打开 PowerShell。
3. 逐条执行：

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install_windows.ps1
   ```

安装程序会覆盖本机程序代码，并更新登录启动任务和快捷方式。邮箱设置、系统凭据库中的客户端密码/授权码及本地晨报状态会继续保留，因为它们存储在独立的本地用户目录中。

## 五、隐私与数据存储

- 不需要将邮箱密码写入配置文件。
- 邮箱凭据通过 Windows 本机系统凭据库保存。
- 本地状态目录：`%APPDATA%\MailBriefingAssistant`，主要包括邮箱设置、邮件 UID 同步状态、待晨报元数据、最近一次晨报与运行日志。
- 为了重新打开小插件后能查看最近晨报，程序会在本机保存发件人、主题、分类、时间和最多 220 字的正文摘要；不保存完整邮件正文或附件。摘要可能包含邮件中的个人信息，因此仅保存在本机，不会同步到 GitHub 或上传到云端 AI 服务。
- 源代码仓库不包含你的邮箱凭据、真实邮件内容或本机状态文件。
- 当前分类使用可解释的关键词规则，并非大模型语义分类，可能出现误分类。
- 当前版本只扫描收件箱 `INBOX`，每次最多处理 100 封新邮件；首次扫描最多检查最近 100 封中的近 24 小时邮件。

## 六、常见问题

### 1. 正文摘要为什么为空？

旧版晨报缓存只保存了发件人、主题、分类和时间，不包含正文摘要。新版启动时会尝试通过只读 IMAP 连接，为仍可访问的旧邮件补齐最多 220 字的摘要；这需要对应邮箱仍处于启用状态且连接正常。若旧邮件已被删除或邮箱暂时无法连接，卡片可能仍显示“暂无正文摘要”，新发现的邮件则会正常保存摘要。

### 2. PowerShell 提示无法执行脚本

在当前 PowerShell 窗口先运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

然后再运行：

```powershell
.\install_windows.ps1
```

确认命令是在包含 `install_windows.ps1` 的解压目录执行。

### 3. 提示找不到 Python Launcher 或无法创建虚拟环境

安装 Python 3.11 或更新版本，并在安装界面勾选 **Add Python to PATH**。安装结束后关闭并重新打开 PowerShell，再执行 `py -3 --version` 检查。

### 4. 邮箱无法连接

- Gmail：确认账户支持当前客户端登录方式；不要使用普通网页登录密码替代应用专用密码。
- QQ 邮箱：确认 IMAP/SMTP 服务已启用，输入的是授权码。
- 清华邮箱：确认服务器地址、端口和客户端专用密码符合学校当前设置。
- 检查网络是否允许访问对应 IMAP SSL 服务器的 993 端口。

### 5. 关闭后找不到桌面小插件

从开始菜单重新打开 **邮件助手**。如果该快捷方式不存在，重新运行最新版本的 `install_windows.ps1`。

### 6. 到了提醒时间却没有弹出晨报

确认电脑没有关机、Windows 用户已经登录、小插件正在运行、邮箱已启用且连接测试通过，并检查 Windows 通知/安全软件是否阻止程序运行。也可以打开设置窗口手动检查。

### 7. 想看运行日志

打开文件资源管理器，在地址栏输入：

```text
%APPDATA%\MailBriefingAssistant
```

查看 `mail-briefing.log`。分享日志前请先检查并移除任何个人信息。

## 项目文件

- `mail_briefing.py`：桌面小插件、邮件摘要展示、设置界面、IMAP 邮件检查与分类逻辑。
- `install_windows.ps1`：安装依赖、创建启动任务和开始菜单快捷方式。
- `launch_widget.bat`：只启动桌面悬浮小插件。
- `launch.bat`：打开邮箱配置与晨报列表窗口。
- `requirements.txt`：Python 依赖。
- `.github/workflows/validate.yml`：自动检查 Python 源码语法。
